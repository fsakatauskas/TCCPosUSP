# Objetivo

Investigar como a aplicação conjunta de OpenAPI, estratégias de versionamento, governança e
mecanismos de segurança pode melhorar a qualidade, a manutenção e a evolução de APIs corporativas.

Como objetivos específicos, pretende-se:

- estudar os conceitos fundamentais de APIs REST;
- analisar o uso do OpenAPI na documentação e padronização de contratos;
- avaliar diferentes estratégias de versionamento;
- estudar modelos de governança de APIs;
- investigar mecanismos de segurança como OAuth 2.0, JWT e API Keys;
- desenvolver um estudo de caso aplicando as boas práticas pesquisadas.

O objetivo é mensurável ao final da pesquisa por meio dos indicadores definidos na metodologia:
cobertura do contrato OpenAPI, número de quebras de compatibilidade detectadas, esforço de
manutenção das rotas versionadas e conformidade com a lista de riscos da OWASP API Security
Top 10 [@owasp2023].
