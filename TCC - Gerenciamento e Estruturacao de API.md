TCC — Gerenciamento e Estruturação de APIs
Tema
Gerenciamento e Estruturação de APIs: Boas práticas utilizando OpenAPI, Versionamento, Governança e Segurança.

--------------------------------------------------------------------------------

Resumo
Este Trabalho de Conclusão de Curso tem como objetivo investigar como a adoção de boas práticas no gerenciamento e na estruturação de APIs contribui para o desenvolvimento de sistemas mais seguros, padronizados, escaláveis e de fácil manutenção. A pesquisa abordará conceitos relacionados à especificação OpenAPI, estratégias de versionamento, governança e segurança de APIs, complementados por uma implementação prática que demonstre a aplicação desses conceitos em um cenário real.

--------------------------------------------------------------------------------

Palavras-chave
OpenAPI
Versionamento
Governança
Segurança

--------------------------------------------------------------------------------

Motivação
Minha motivação para escolher este tema está relacionada à experiência na área de engenharia de software e ao interesse em boas práticas para o desenvolvimento e gerenciamento de APIs. Pretendo investigar como a utilização de padrões como OpenAPI, estratégias de versionamento, governança e mecanismos de segurança contribuem para a criação de APIs mais padronizadas, escaláveis e confiáveis. A pesquisa será baseada em revisão bibliográfica e na implementação de um estudo de caso, permitindo analisar a aplicação dessas práticas em um cenário real e identificar seus benefícios para a manutenção, integração entre sistemas e evolução contínua das aplicações.
Objetivo Geral
Investigar como a aplicação de OpenAPI, estratégias de versionamento, governança e mecanismos de segurança podem melhorar a qualidade, a manutenção e a evolução de APIs corporativas.

--------------------------------------------------------------------------------

Objetivos Específicos
Estudar os conceitos fundamentais de APIs REST.
Analisar o uso do OpenAPI na documentação e padronização.
Avaliar diferentes estratégias de versionamento.
Estudar modelos de governança de APIs.
Investigar mecanismos de segurança como OAuth2, JWT e API Keys.
Desenvolver um estudo de caso aplicando as boas práticas pesquisadas.

--------------------------------------------------------------------------------

Problema de Pesquisa
Como a adoção de práticas de documentação, versionamento, governança e segurança influencia a qualidade e a manutenção de APIs utilizadas em ambientes corporativos?

--------------------------------------------------------------------------------

Hipótese
A utilização conjunta de OpenAPI, versionamento estruturado, governança e mecanismos de segurança reduz problemas de integração, facilita a manutenção e melhora a evolução contínua das APIs.

--------------------------------------------------------------------------------

Metodologia
O trabalho será desenvolvido utilizando:
Revisão bibliográfica;
Pesquisa exploratória;
Estudo de caso;
Desenvolvimento de uma API REST;
Análise dos resultados obtidos.
